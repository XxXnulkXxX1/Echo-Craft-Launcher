Echo Craft Launcher 1.0.0 · 安装说明
开发者：XxXnulkXxX（非官方，基于 PCL2 模块结构独立实现）

一、给朋友安装（推荐）
1. 把 EchoCraftSetup.exe（约 140 KB）单独发过去即可。
2. 双击运行；若系统提示「未知发布者」，点「更多信息 → 仍要运行」。
3. 选择安装位置（默认 D:\EchoCraftLauncher\Program），点「开始安装」。
4. 安装器会自动完成：
   - 检查 .NET 10 桌面运行时；缺少时询问并自动下载官方安装器静默安装（约 57 MB）；
   - 下载完整程序包（约 2.8 MB）；
   - 解压到安装目录，并按勾选创建桌面 / 开始菜单快捷方式。
5. 游戏数据（实例、资源、存档、配置）固定保存在 D:\EchoCraftLauncher，重装/升级不会清空。

二、系统要求
- Windows 10 / 11 x64
- .NET 10 Desktop Runtime（安装器可自动装）
- Microsoft Edge WebView2 Runtime（Win11 及新版 Win10 一般已自带；缺失时安装器会提示下载页）

三、注意
- 安装器未做代码签名，SmartScreen 提示属正常现象。
- 当前程序包托管在临时 CDN（aka.doubaocdn.com/s/9WJyiGmukC），长期分发建议把
  EchoCraftLauncher-1.0.0.zip 放到自己的网盘 / GitHub Release / 服务器后，
  修改 EchoCraftLauncher-Setup/SetupForm.cs 里的 PackageUrl 再重新编译。
- 离线安装：把 EchoCraftLauncher-1.0.0.zip 与 EchoCraftSetup.exe 放在同一目录，
  安装器会优先使用本地包，完全不联网（运行时仍按需检查）。

四、目录
- EchoCraftSetup.exe              网络安装器（单文件，140 KB）
- EchoCraftLauncher-1.0.0.zip     完整程序包（约 2.8 MB，可作离线安装包）
